## PWA
The hub works offline after an online visit. Nested apps manage their own offline support.
Letter-free workshop icons include an SVG favicon, 180px Apple touch icon, 192px and 512px PWA icons, and a 512px maskable icon.
Increment the service worker cache version when changing shell assets.
